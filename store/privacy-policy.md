# Kebijakan Privasi Sinelog

Terakhir diperbarui: 24 November 2026

Sinelog adalah aplikasi untuk mencari film dan mencatat koleksi film pribadi.
Kebijakan ini menjelaskan data apa yang dipakai aplikasi dan ke mana data itu
dikirim.

## Data yang disimpan di perangkat

Koleksi film dan rating pribadi kamu disimpan **hanya di perangkatmu**, di
database lokal aplikasi. Data ini tidak dikirim ke server mana pun, termasuk
server pengembang. Data terhapus jika aplikasi di-uninstall atau datanya
dibersihkan lewat pengaturan Android.

## Data yang dikirim ke pihak ketiga

Untuk menampilkan daftar dan poster film, aplikasi menghubungi
[The Movie Database (TMDB)](https://www.themoviedb.org):

- **Kata kunci pencarian** yang kamu ketik dikirim ke API TMDB untuk mencari
  film. Kata kunci tidak disimpan oleh aplikasi.
- **Gambar poster** diunduh dari server gambar TMDB.

Seperti permintaan internet pada umumnya, server TMDB dapat menerima alamat IP
perangkatmu. Penggunaan data oleh TMDB diatur oleh
[kebijakan privasi TMDB](https://www.themoviedb.org/privacy-policy).
Semua komunikasi memakai HTTPS (terenkripsi).

## Yang tidak dilakukan aplikasi

- Tidak ada akun, login, atau pendaftaran.
- Tidak mengumpulkan nama, email, lokasi, kontak, atau ID perangkat.
- Tidak ada iklan, analitik, atau pelacakan.
- Tidak ditujukan untuk anak di bawah 13 tahun.
